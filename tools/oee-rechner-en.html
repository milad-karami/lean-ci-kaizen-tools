OEE: Measuring equipment effectiveness

The Overall Equipment Effectiveness rates a production machine between 0 and 100% from three factors: Availability × Performance × Quality. The example from the video is stored 1:1 (OEE ≈ 66%) and is fully editable – change a number and the time cascade, the factors and the OEE follow immediately. The course exercise “KaffeKönig · Station 3” is pre-filled as a separate example – including a step-by-step mapping of every number from the task text.

How saving works +

This HTML file is your document. Everything you enter ends up in exactly this file when you save – just like a Word document. If you pass the file on, all calculations in it go with it.

Save (green button or Ctrl+S) backs up the current state – without any prompt. As long as no working file of your own has been created, the state is kept in the browser and will be there again the next time you open it.

Save as (under “Calculations”) creates a file on your hard drive. This is the only place where you are asked where to save. After that, every further Save writes silently into exactly that file.

The first time: open the file, click “Calculations” and then Save as. From then on the green button is enough.

Saved automatically: as soon as a calculation has been saved once, the tool backs up every further change by itself after a few seconds.

If something goes wrong: the tool continuously keeps an interim state in the browser. If the browser crashes or you close the window by accident, your work is there again the next time you open it.

Note on browsers: writing directly to the file currently works in Chrome and Edge. In Firefox and Safari everything stays saved in the browser – the file itself remains unchanged.
