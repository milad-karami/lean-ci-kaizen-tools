How saving works +

This HTML file is your document. Everything you enter is written to exactly this file when you save – just like a Word document. If you pass the file on, all analyses are included.

Save (green button or Ctrl+S) saves the current state – without any questions. As long as no working file of your own has been created, the state is kept in the browser and will be there again the next time you open it.

Save as (under »Analyses«) creates a file on your hard drive. This is the only place where you are asked where to save. After that, every further Save writes silently to exactly this file.

The first time: Open the file, click »Analyses« and then Save as. From then on the green button is enough.

Saved automatically: Once an analysis has been saved, the tool saves every further change by itself after a few seconds.

In case something goes wrong: The tool continuously keeps an interim state in the browser. If the browser crashes or you close the window by mistake, your work will be there again the next time you open it.

Note on browsers: Writing directly to the file currently works in Chrome and Edge. In Firefox and Safari everything stays saved in the browser – the file itself then remains unchanged.
